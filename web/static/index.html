    Settings

    Assistant

    A model on your own Ollama server reads your files and answers questions. Nothing is sent anywhere else.

    With a hosted provider, everything the assistant and the file reader read is sent to it: profiles, files, values. Free models may keep and train on what they're sent. Use it with test data, or only if you accept that.

    Reference data

    Public medical references the assistant looks things up in, kept on this server. The app contacts these sources only when you press a button here, and what you look up is never sent anywhere.

    Import recipes

    Small programs the reader wrote for formats it saw before, like a device's export. Each was approved by someone here, and it reads its format in full without the model. They run with no access to anything but the file.

    People

    Backups

    A backup is everything: profiles, files, values, chats. It stays encrypted, and opens only with the password (or recovery key) the records have when it's made. To move to a new server, set it up with "Restore from a backup".
